# Gaurav Barsker Portfolio

A responsive portfolio website built with HTML, CSS, and minimal JavaScript.


## Files
- `index.html` — content and page structure
- `style.css` — styling, layout, and responsive rules
- `script.js` — mobile navigation and footer year


## Before publishing
1. Replace `YOUR_EMAIL_HERE` in `index.html` with your email address.
2. Replace the generic GitHub link with your profile URL.
3. Add project repository links and screenshots when ready.
4. Review all project and achievement descriptions for accuracy.
